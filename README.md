# Caesar Cipher Web App

A web-based Caesar Cipher tool built with **Java Spring Boot** and an HTML/CSS/JavaScript frontend.

## Features
- Encrypt and decrypt text with any shift (1-25)
- Interactive cipher disc controlled by a slider
- "Try all 25 shifts" brute-force view

## Tech Stack
- Java 17, Spring Boot 3.2.5, Maven
- HTML, CSS, JavaScript
- JUnit (testing)
- Jenkins (CI/CD pipeline)

## API Endpoints
| Method | Endpoint         | Description       |
  - - -     - - -              -   -   -  
| POST   | /api/encrypt     | Encrypt text      |
| POST   | /api/decrypt     |Decrypt text       |
| POST   | /api/bruteforce  | Try all 25 shifts |
